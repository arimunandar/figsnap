    Local or hosted

    Running it yourself keeps every byte on this machine and is the only way to get the directory browser and the skill installer, which need a filesystem. A Cloudflare deployment is for when the agent is somewhere else — a cloud session, CI, a teammate — and it requires a token, since there is no 127.0.0.1 to hide behind on a public address.

    Either way the relay stores nothing: image URLs re-render through this plugin rather than serving a cached copy, so no part of your design is ever at rest.

    Running it yourself

    Run this in the plugin's project directory and leave it running:

    npm run relay

    A local relay has no accounts: it binds to 127.0.0.1, so anything already on your machine could reach it anyway. Set RELAY_TOKEN if you want one anyway, and paste it into Settings above. 

    RELAY_TOKEN=$(openssl rand -hex 16) npm run relay

    RELAY_PORT changes the port. Figma blocks any address the manifest does not list, so a different port also means editing networkAccess.devAllowedDomains in manifest.json and re-importing the plugin — Figma caches the manifest.

    Checking it from a terminal

    curl -s http://localhost:3055/health

    Hosting it on Cloudflare

    Deploy once, from the plugin's project directory: 

    npx wrangler login
npm run worker:deploy

    A hosted relay has accounts, and signing in happens in this panel: Sign in at the top of this page asks for an email and a password, stores the token it gets back, and brings the socket and the HTTP API up without another click. The same form is what the plugin opens with when no session is stored.

    The password is sent to your own relay over HTTPS and is never stored here — only the token it returns is, per user rather than in the project. The relay also serves /login as an ordinary web page if you would rather type the password into a browser, where a password manager can fill it.

    Each account gets its own room. A token reaches the designs of the plugin signed in with that same account and nobody else's, so several designers can share one relay without colliding. Passwords are stored as a chained PBKDF2 hash, tokens only as a SHA-256 hash, and signing in again issues a fresh token while older ones keep working until revoked.

    A newly deployed address must be added to networkAccess.devAllowedDomains in manifest.json — the exact host, not a *.workers.dev wildcard, which would let this plugin reach every Worker on the internet — followed by a re-import. The address offered above is already listed.

    Two routes stay local-only on a hosted relay and answer 501: browsing directories and installing the Claude Code skill, both of which need a filesystem.

    The relay serves the whole manual over HTTP at /docs, and as Markdown at /docs.md for pasting into an agent.
