    Claude Code skill

    .claude/skills/figsnap/SKILL.md teaches an agent these endpoints, and figsnap-extractor is an agent that pulls several nodes and reports a summary rather than tens of kilobytes of CSS. Both are generated with this relay's address already in them.

    The relay serves them; it cannot write them, having no filesystem of its own. Two commands in the project you want them in: 

    mkdir -p .claude/skills/figsnap .claude/agents
curl -s RELAY/skill/SKILL.md > .claude/skills/figsnap/SKILL.md
curl -s RELAY/skill/figsnap-extractor.md > .claude/agents/figsnap-extractor.md

    Checking it from a terminal

    curl -s https://your-relay.workers.dev/health

    Running your own relay

    The address above is one deployment; yours is two commands, from the plugin's project directory: 

    npx wrangler login
npm run worker:deploy

    Signing in happens in this panel: Sign in at the top asks for an email and a password, stores the token it gets back, and brings the socket and the HTTP API up without another click. It is what the plugin opens with when no session is stored.

    The password is sent to your own relay over HTTPS and is never stored here — only the token it returns is, per user rather than in the project. The relay also serves /login as an ordinary web page if you would rather type the password into a browser, where a password manager can fill it.

    Each account gets its own room. A token reaches the designs of the plugin signed in with that same account and nobody else's, so several designers can share one relay without colliding. Passwords are stored as a chained PBKDF2 hash, tokens only as a SHA-256 hash, and signing in again issues a fresh token while older ones keep working until revoked. Your saved set is kept per account too, so it follows you between machines — node ids and layer names, never a design.

    A newly deployed address must be added to networkAccess.devAllowedDomains in manifest.json — the exact host, not a *.workers.dev wildcard, which would let this plugin reach every Worker on the internet — followed by a re-import. The address offered above is already listed.

    Two routes stay local-only on a hosted relay and answer 501: browsing directories and installing the Claude Code skill, both of which need a filesystem.

    The relay serves the whole manual over HTTP at /docs, and as Markdown at /docs.md for pasting into an agent.
